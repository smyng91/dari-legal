1. 谁可以使用 Dari

您必须年满 18 周岁；如果您所在地的法定成年年龄更高，则须达到该年龄。

2. Dari 是什么

Dari 是一款将您连接到其他公司（Anthropic、OpenAI、DeepSeek、Tavily、Google 和 Apple）所运营的 AI、搜索和地图服务的应用；对于需要 API 密钥的服务，本应用会使用您从这些公司获取的 API 密钥。我们不运营、训练或控制它们的 AI 模型。

  • 您必须遵守您所使用的每项服务的条款和使用政策：
  • Anthropic：https://www.anthropic.com/legal/aup
  • OpenAI：https://openai.com/policies/usage-policies/
  • DeepSeek：https://cdn.deepseek.com/policies/en-US/deepseek-terms-of-use.html
  • Google：https://ai.google.dev/gemini-api/terms

4. AI 的回答可能有误

  • 您是在与 AI 模型而非真人对话。它们的回答、图片和摘要可能有误、不完整、过时或具有冒犯性，并且即使出错也可能显得十分肯定。
  • 回答并非专业建议。请勿依赖这些回答做出医疗、法律、财务、安全或其他可能带来严重后果的决定；请咨询具备相应资质的人士。
  • 地点信息（评分、营业时间、地址）来自 Google Maps 或 Apple Maps，网页结果来自第三方网站。这些信息可能不准确。请自行核实重要信息。
