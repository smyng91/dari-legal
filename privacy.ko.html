사용자는 자신의 API 키를 사용하므로 각 서비스의 고객이 되며, 서비스가 받은 정보에는 해당 서비스의 개인정보 처리방침과 보관 정책이 적용됩니다. 우리는 그 사본을 받지 않습니다. 각 서비스는 자체 방침에 따라 소재 국가 외의 국가에서도 정보를 처리할 수 있습니다.

설정 → 고급에서 직접 서버 주소를 지정하면 요청은 그 서버로 전송되며, 그 서버의 운영자(대개 사용자 본인)가 처리 방식을 정합니다.

사용자의 선택. 키를 추가하는 것은 Dari가 그 서비스로 정보를 보내는 데 동의하는 것입니다. 저장하기 전에 어떤 정보가 전송되는지 앱이 안내합니다. 중단하려면 설정 → API 키에서 키를 삭제하세요. Apple 지도는 사용자가 허용한 뒤에만 사용하며, 설정 → 장소에서 끌 수 있습니다. 그 서비스가 필요한 기능은 더 이상 작동하지 않습니다.

연결된 계정. 설정 → 계정에서 Gmail 및 Google 캘린더, Outlook 메일 및 캘린더 또는 Microsoft Teams를 연결하면, Dari가 기기에서 Google 또는 Microsoft에 로그인하고 로그인 정보를 시스템 보안 저장소에 보관합니다. 메일, 캘린더 또는 채팅에 대해 물으면 답변하는 AI 모델이 앱을 통해 이를 검색하고 읽을 수 있습니다. 앱은 Google 또는 Microsoft에서 메일, 일정 또는 채팅 메시지를 가져와, 읽은 내용을 대화의 일부로 그 메시지에 답변하는 AI 서비스에 보냅니다. DeepSeek는 계정을 읽을 수 없지만, 이미 채팅에 들어간 내용은 이후 답변하는 서비스에 그 채팅과 함께 전송됩니다. 이메일, 일정, Teams 메시지는 보낼 내용을 그대로 보여 주는 카드에서 사용자가 보내기를 누를 때만 전송됩니다. 우리는 이 중 어떤 것도 받지 않습니다. Google API에서 받은 정보에 대한 Dari의 사용 및 전송은 제한적 사용(Limited Use) 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다. 이 정보는 앱에서 사용자의 요청에 답하는 데에만 쓰이며, 광고나 AI 모델 학습에는 쓰이지 않습니다. AI 서비스가 받은 내용으로 할 수 있는 일은 그 서비스의 약관이 정합니다(일부 무료 API 요금제는 모델 개선에 사용하는 것을 허용합니다). 중단하려면 설정 → 계정에서 연결을 해제하세요. Google 또는 Microsoft 계정 설정에서도 접근 권한을 삭제할 수 있습니다.

4. 사용자가 보내는 신고

답변을 신고하면 Dari는 답변 내용, 사용자가 고른 사유와 메모, 모델 이름, 앱 버전, 플랫폼(iOS 또는 Android)을 우리에게 보냅니다. 질문은 사용자가 선택한 경우에만 포함됩니다. 신고는 유해한 답변을 찾아 줄이는 데 사용하며, 최대 12개월 동안 보관하고 요청하면 더 일찍 삭제합니다. 신고를 이메일로 보내는 경우 우리는 사용자의 이메일 주소도 알게 됩니다.

5. 하지 않는 일

  • 분석, 광고, 추적, 충돌 보고를 하지 않으며 광고를 위해 정보를 판매하거나 공유하지 않습니다.
  • 앱은 설정 → 장소에서 “내 위치로 주변 장소 찾기”를 켜고 허용한 경우에만 위치를 읽습니다. 이때 시스템에 대략적인 위치를 요청하고 약 1km 단위로 반올림해 장소 검색과 함께만 보냅니다. 그곳이나 시스템 설정에서 끌 수 있습니다. 지도 서비스는 IP 주소로 대략적인 지역을 추정할 수도 있습니다.
  • 상품을 사는 것에 관한 답변이면, 가격과 평점이 담긴 상품 카드를 보여 주기 위해 기기가 웹 검색이 찾은 쇼핑몰과 리뷰 페이지, 그리고 상품 사진을 그 웹사이트에서 직접 불러옵니다. 다른 웹 페이지를 방문할 때처럼 그 사이트는 IP 주소와 요청한 페이지를 알 수 있으며, 앱은 채팅 내용을 보내지 않습니다.
  • 카메라와 사진은 사진을 찍거나 고를 때만 사용합니다. 사진 속 위치 정보(EXIF)는 저장하거나 보내기 전에 제거됩니다.
  • 제안된 일정, 연락처, 전화번호, 이메일 또는 메시지를 다른 앱에서 열기 전에 수정할 수 있습니다. Dari가 앱을 바로 열도록 허용하면(답변이 처음으로 작업을 제안할 때 물어보며, 설정 → 기기 작업에서 바꿀 수 있습니다) 답변이 도착하는 즉시 제안된 내용이 채워진 대상 앱이 열립니다. 시스템 연락처 선택기를 사용하면 Dari는 직접 고른 전화번호나 이메일 주소 하나만 받습니다. 선택한 정보는 임시 초안에만 보관되며 채팅 기록과 AI 요청에는 포함되지 않습니다. 대상 앱이 열리면 초안의 정보가 해당 앱에 전달되며 그 앱의 개인정보 처리방침이 적용됩니다. 전송, 저장, 통화는 그 화면에서 직접 확인합니다. 이 기능을 위해 Dari는 휴대폰의 주소록, 캘린더 또는 메시지에 대한 접근 권한을 요청하지 않습니다. 받은편지함이나 캘린더는 사용자가 연결한 계정(3항)을 통해서만 읽습니다. Android와 iOS 17 이상에서는 캘린더 편집기를 열 수 있으며, 이전 iOS 버전에서는 일정 내용을 공유할 수 있습니다.
  • 파일은 시스템 파일 선택 화면에서 고를 때만 읽습니다. 파일의 텍스트는 기기에서 읽으며, PDF는 그대로, 다른 파일은 텍스트로 그 메시지에 답하는 AI 서비스로 보냅니다. 모델이 계속 참고할 수 있도록 파일은 이후 메시지마다 다시 보내지며, 더 새로운 파일로 바뀌거나 모델이 보는 대화 범위를 벗어나면 보내지 않습니다.

6. 보관 기간과 삭제 방법

  • 기기: 삭제할 때까지 보관합니다. 메시지(길게 누르기), 채팅, 주제, 메모리를 각각 삭제할 수 있고, 설정 → 저장 공간 → 모든 채팅 삭제로 모든 채팅을 한 번에, 설정 → API 키에서 각 키를 지울 수 있습니다. 앱을 삭제하면 데이터가 지워집니다. 단, iOS에서는 앱을 삭제해도 API 키가 키체인에 남으며(다른 앱은 읽을 수 없습니다), Dari를 다시 설치하면 Dari가 이를 지웁니다. 바로 지우려면 앱을 삭제하기 전에 설정 → API 키에서 키를 삭제하세요. 계정 연결은 설정 → 계정에서 해제할 수 있습니다.
  • 각 서비스: 해당 서비스의 개인정보 처리방침에 따릅니다. 서비스가 보관한 정보에 대해서는 위 링크를 통해 해당 서비스에 문의하세요.
  • 신고: 4항에서 설명한 대로 최대 12개월.

7. 안전성 확보 조치

연결은 암호화됩니다. API 키는 시스템 보안 저장소에 보관하며 파일이나 로그에 기록하지 않습니다. 앱 파일은 백업에서 제외되며, iOS에서는 기기가 잠겨 있는 동안 암호화됩니다. 삭제한 메시지는 덮어써집니다. 완벽하게 안전한 방법은 없습니다. 루팅되었거나 탈옥된 기기에서는 다른 소프트웨어가 앱 데이터를 읽을 수 있습니다.

8. 아동

Dari는 만 18세 미만을 대상으로 하지 않으며, 우리는 아동의 정보를 알면서 받지 않습니다.

9. 이용자의 권리

거주 지역의 법(예: 개인정보 보호법, GDPR, 영국 GDPR, 캘리포니아 소비자 개인정보 보호법)에 따라 정보의 열람, 정정, 삭제, 처리 정지를 요구하고 감독 기관에 민원을 제기할 권리가 있을 수 있습니다. 우리는 사용자가 보낸 신고 외에는 사용자에 대한 정보를 갖고 있지 않으므로, 대부분의 권리는 앱 안에서 직접 행사할 수 있습니다. 신고에 대해서는 우리에게, 서비스가 보관한 정보에 대해서는 해당 서비스에 문의하세요.

10. 개인정보의 국외 이전

서비스를 사용하면 정보는 보내는 순간 기기에서 해당 서비스로 네트워크를 통해 전송됩니다. Anthropic, OpenAI, Tavily, Google, Apple은 미국에 소재하며, DeepSeek는 중화인민공화국에 소재하고 정보를 그곳에 저장한다고 밝히고 있습니다. 각 서비스는 자체 방침에 따라 다른 국가에서도 정보를 처리할 수 있습니다. 이전 항목은 3항에 적힌 정보이고, 목적은 사용자의 요청에 답하는 것이며, 보관 기간은 각 서비스의 방침에 따릅니다. 해당 서비스의 키를 추가하지 않거나 삭제하면 이전을 거부할 수 있으며, 이 경우 그 서비스가 필요한 기능은 사용할 수 없습니다.
